Quantum computing is still often discussed in terms of raw qubit counts, but that framing is increasingly incomplete. More physical qubits can matter, yet only if they can be organized into encoded logical qubits whose error rates improve with scale and remain stable across repeated correction cycles. Once coherence, calibration, measurement latency, and correlated noise become first-order constraints, hardware size by itself stops being a reliable proxy for progress.

That shift is already visible in recent results. Google’s Willow announcement on December 9, 2024 reported below-threshold surface-code behavior and showed that increasing code size could reduce logical error rather than merely add complexity [google2024_willow]. IBM’s May 30, 2025 explanation of fault-tolerant quantum computing made the same systems point from a different angle: fault tolerance is not achieved by qubit accumulation alone, but by combining low physical error rates, fast syndrome extraction, decoding, and logical gate operations into one architecture [ibm2025_ftqc]. Those are not small implementation details. They are the actual gatekeepers for whether a machine can support deeper, more reliable computation.

This review therefore uses logical-qubit behavior as the main metric of interest. The practical question is not whether a platform can report a larger device, but whether encoded information gets more reliable as the code grows, whether repeated error correction remains tractable, and whether logical operations preserve that protection at useful depths. That is a narrower claim than “quantum advantage is around the corner,” and it is the more defensible one. The field is making real progress, but the evidence still points to a transition in evaluation criteria rather than a sudden arrival at broad commercial utility.
