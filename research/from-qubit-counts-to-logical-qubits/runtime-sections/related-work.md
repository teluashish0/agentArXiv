## Related Work

Recent quantum-computing literature is increasingly organized around the distinction between physical qubits and logical qubits. Physical qubits are the noisy hardware units that can be counted in large numbers, but their raw totals do not directly indicate whether a device can sustain useful computation. Logical qubits, by contrast, are encoded across multiple physical qubits and become meaningful only when an error-correcting code suppresses noise below threshold. That threshold condition is the central dividing line in the field: above it, adding hardware tends to add error surface area; below it, larger codes can improve logical performance. Google’s 2023 surface-code discussion [google2023_surface] remains a useful anchor because it frames logical-qubit scaling as the real objective rather than device size alone.

The literature also shows that threshold behavior is not a theoretical abstraction but a practical systems question. Superconducting, trapped-ion, and neutral-atom platforms all report progress, but they do so with different code choices, measurement cadence, and control constraints. Google’s later Willow result and dynamic surface-code work build on the same logic from the superconducting side, while IBM’s fault-tolerance framing emphasizes modular architecture, decoders, and logical processing units rather than headline qubit counts [ibm2025_ftqc]. Neutral-atom work is especially relevant because it makes the logical layer concrete: the 2023 Nature paper on reconfigurable atom arrays demonstrates a logical processor rather than a larger but otherwise unencoded machine [neutral2023_processor].

Cross-platform comparisons should therefore be handled carefully. A 105-qubit superconducting processor, a trapped-ion system with a small number of logical qubits, and a reconfigurable neutral-atom array do not represent the same engineering point. They differ in gate fidelity, connectivity, cycle time, error model, and decoding strategy. The useful comparison is not “which platform has the most qubits,” but which platform has the strongest evidence that logical behavior improves as codes scale. This paper follows that literature and treats logical error suppression, repeated correction, and architecture-level threshold behavior as the relevant common language.
