## Experimental Setup

This paper is a review and perspective article, not an original experimental study. Its “setup” is therefore the scope and evaluation lens used to compare recent quantum-computing results. The review focuses on platform milestones that are already reported in the literature or in vendor announcements, and it evaluates them using a small set of concrete criteria: logical error suppression, repeated quantum error correction (QEC), decoder latency, and the separation between demonstrated results and roadmap projections.

The scope is intentionally broad but bounded. On the superconducting side, the review centers on Google’s Willow milestone from December 9, 2024, where the main evidence is below-threshold surface-code scaling, and on Google’s January 13, 2026 dynamic-surface-code update, which changes the hardware layout and control pattern without changing the basic question of whether logical performance improves with scale [google2024_willow] [google2026_dynamic]. IBM’s June 10, 2025 large-scale FTQC announcement is used as a roadmap-and-architecture counterpoint because it makes the systems-engineering requirements explicit [ibm2025_large].

The evaluation lens is conservative. A result counts as stronger evidence when it shows that logical error rates fall as code distance increases, that multiple correction rounds can be sustained, and that classical decoding does not dominate the error-correction loop. Decoder latency matters because a logical qubit is only useful if the syndrome-processing pipeline can keep up with the hardware. The review also treats vendor roadmaps separately from demonstrations, even when both appear in the same release. That distinction prevents a common failure mode in the field: conflating a present experimental milestone with a future target.

The resulting comparison is not intended to crown a winner. It is meant to answer a narrower question: which platforms are now producing credible evidence that the logical layer, not the raw qubit count, is the right unit of progress. That lens is consistent with current reporting across the major platforms and with the recent shift in how researchers describe fault tolerance, scalability, and practical quantum advantage.
